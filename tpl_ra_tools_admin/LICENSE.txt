This template additionally depends at runtime on Atum's own compiled CSS and
JavaScript assets (registered by the Atum extension, itself unmodified and
required to remain installed) for layout, responsive and interaction behaviour.

media/css/vendor/fontawesome-free/fontawesome.min.css is an unmodified copy of
the Font Awesome Free CSS bundled with Joomla's Atum template, provided here so
Joomla's per-template media-override resolution picks up the complete icon font
(the shared core copy at media/vendor/fontawesome-free/ ships without any
@font-face declarations). No webfont binaries are duplicated by this package;
this CSS file's relative font URLs resolve to the shared core webfont files.
